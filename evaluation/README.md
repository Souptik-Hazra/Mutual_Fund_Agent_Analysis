# Personal agent evaluation

`research-routing.json` is a small deterministic routing benchmark. Run `mfa-evaluate-agent` from the repository root after installing the `agents` extra. It checks specialist selection without API keys, external calls or database fixtures. Exact-match accuracy is the main score; per-intent precision and recall show which specialist routing needs improvement. `research-routing.json` covers all eight specialists (fund, category, actual exposure, portfolio, security, events, social and documents) and mixed-intent prompts. `research-evidence.json` covers positive, negative, stale, malformed and unsupported-claim evidence cases. Keep examples reviewed and deterministic; live-provider results must be evaluated separately from this offline suite.
